# سیستم پژوهش و انتشار خودکار کانال Gamification Club

هر روز: جمع‌آوری مطالب از منابع علمی و تخصصی ← امتیازدهی ← انتخاب بهترین ← نگارش پست کوتاه فارسی ← کنترل کیفیت (ماشینی + بررسی مستقل) ← انتشار در تلگرام. اگر چیزی به حد نصاب نرسد، پستی منتشر نمی‌شود.

## کنترل‌ها
- توقف کامل: در گیت‌هاب، تب Actions ← daily-post ← منوی «...» ← Disable workflow.
- اجرای دستی: Actions ← daily-post ← Run workflow. گزینه `task=dry` فقط پیش‌نمایش را به چت خصوصی می‌فرستد.
- تنظیمات (حد نصاب امتیاز، منابع، عبارت‌های جست‌وجو، طول پست): فایل `config.yaml`.
- گزارش هر اجرا: پوشه `reports/`. سوابق: `data/agent.db`.
- ساعت انتشار: در cron-job.org (و پشتیبان آن داخل `.github/workflows/daily.yml`).
